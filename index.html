Pushing methods past their assumptions.

Can LLMs Make Tabular ML Better?
A controlled experiment testing whether LLM-generated semantic features improve XGBoost on structured data — using nested CV, Wilcoxon tests, and Cohen's d to evaluate the hybrid approach properly. The results went against the hypothesis, and that turned out to be the more interesting finding.

AutoInsight — End-to-End AutoML App
A browser-based AutoML tool that trains 7 models in parallel, generates SHAP explainability, and produces LLM-written plain-language insights — with a privacy-preserving design where raw data never leaves the browser.

Quake — Learned Heuristic A* on BSP Geometry
Parsed Quake 1's raw binary map format to build navigation graphs, generated 625k ground-truth pathfinding pairs, then trained learned heuristics that cut A*'s node expansions by 42% while keeping paths near-optimal.

A reproduction of Nakkiran et al. (2019)'s epoch-wise double descent on CIFAR-10 with ResNet-18 under varying label noise — with a mechanistic investigation into what's actually happening at the peak.
